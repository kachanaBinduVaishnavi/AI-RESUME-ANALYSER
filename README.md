# AI Resume Analyzer

An AI-powered web application that analyzes a resume against a job description and identifies matching and missing skills.

## 📌 Project Overview

The AI Resume Analyzer helps job seekers understand how well their resume matches a particular job description.

The application extracts text from an uploaded resume, analyzes the relevant skills, compares them with the job requirements, and displays the matching and missing skills along with a match score.

## ✨ Features

- Upload a resume
- Extract text from the resume
- Compare resume skills with job requirements
- Identify matching skills
- Identify missing skills
- Display a resume match score
- Simple and user-friendly interface

## 🛠️ Technologies Used

- HTML
- SQL
- Resume text extraction
- Git & GitHub
